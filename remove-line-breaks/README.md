# Remove Line Breaks Tool / 改行削除ツール

A simple web application that removes all line breaks (CR, LF, CRLF) from text with a single click. Useful for formatting text or pasting into systems that do not support line breaks.
テキストに含まれる改行（CR, LF, CRLF）をワンクリックで一括削除するシンプルなWebアプリケーションです。文章のフォーマットを整えたい時や、改行が不要なシステムにテキストをペーストする際などに便利です。

## Features / 特徴

- 🚀 **Simple & Fast / シンプルで高速**: All processing is done in the browser's JavaScript, ensuring lightweight operation. / すべての処理はブラウザのJavaScriptで行われるため、動作が軽量です。
- 🔒 **Secure / セキュア**: Your input text is never sent to any external servers. / 入力したテキストが外部サーバーに送信されることはありません。
- 📋 **One-Click Copy / ワンクリックコピー**: Copy the formatted text to your clipboard instantly. / 変換後のテキストをボタン一つでクリップボードにコピーできます。
- 🧹 **Clear Function / クリア機能**: Reset the input and output areas at once. / 入力・出力エリアをまとめてリセットできます。
- 📱 **Responsive / レスポンシブ対応**: Optimized for desktops, smartphones, and tablets. / PCだけでなく、スマートフォンやタブレット環境でも使いやすいデザインです。

## Usage / 使い方

1. Paste or type your text into the "Input" area. / 「元の文章」エリアに、改行を消したいテキストを入力または貼り付けます。
2. Click the "Remove Line Breaks" button. / 「改行を削除する」ボタンをクリックします。
3. The formatted text will appear in the "Result" area. / 「結果」エリアに改行が削除されたテキストが表示されます。
4. Click the "Copy" button to save the result to your clipboard. / 「コピーする」ボタンを押すと、クリップボードに結果が保存されます。

## Getting Started / 実行方法

No special development environment or server setup is required.
特別な開発環境やサーバーの構築は不要です。

1. Clone or download this repository. / このリポジトリをクローンまたはダウンロードします。
2. Ensure the following three files are in the same directory: / 以下の3つのファイルが同じフォルダにあることを確認します。
   - `index.html`
   - `style.css`
   - `script.js`
3. Open `index.html` in your preferred web browser (Chrome, Safari, Edge, etc.) to start using the tool. / `index.html` をお好みのWebブラウザ（Chrome, Safari, Edgeなど）で開くだけですぐに使用できます。
